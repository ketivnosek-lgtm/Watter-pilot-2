# Water Pilot 2

Nová Android aplikace s černým lodním dashboardem. Šest obrazovek: Duisburg, Rotterdam, Hansweert, Terneuzen, Yerseke, MGD Nijmegen.

Stav: vývoj. Žádná ilustrační čísla nejsou prezentována jako živá měření. Při nedostupných zdrojích se zobrazuje pomlčka.

Sestavení: GitHub Actions → Android APK → artifacts.
